## Parent

#25（地图：C 端（Web + H5）——用户自助侧可演示产品）

## What to build

- **AI 管家 Tab**：聊天式界面（气泡对话、宠物上下文选择、文字与图片输入、发送中/失败状态）；每条回答展示风险三色标识、可能原因、行动建议；**每条回答下方固定合规标识文案**；红色等级置顶「就医准备清单」（可复制）；展示今日剩余次数，超限时友好提示（不引导升级）；历史记录入口（咨询列表 / 详情）。
- **消息中心**：合并展示健康预警与预约状态变化（时间倒序），未读角标；点预警进详情（证据：指标 / 阈值 / 实际值 / 窗口），点预约消息进「我的预约」详情。

## Acceptance criteria

- [ ] 提问 → 收到分级回答 → 气泡渲染正确（三色、原因、建议、标识文案）
- [ ] 红色等级显示就医准备清单且可复制
- [ ] 用满 3 次后第 4 次给出「今日 3 次已用完」提示（与 429 响应一致）
- [ ] 图片提问可上传并出结果（走一期文件上传）
- [ ] 消息中心两类来源都在；未读角标随查看归零
- [ ] AI 失败 / 超时时界面有「稍后重试」，不死等、不白屏

## Blocked by

- C 端 AI 问答接口
- C 端消息与服务预约接口



## 补充（2026-09-23 大厂规划盘问）

- **图片在客户端预压到约 1300×1300 等效像素再上传**（ADR-0008 的约定，一期未落地，本票实现）；头像走同样的客户端压缩（上限 ≤ 2MB）。
- **标识的展示要求**（研究结论）：每条回答的标识行**不可折叠、不可截断、复制时带上**，字型颜色清晰可辨；对话页另有**常驻界面标识**（顶部或底部，不随滚动消失、不可关闭）：`本服务内容由人工智能（AI）生成合成，仅供参考，不构成诊断。`
- 追加验收项：复制回答到剪贴板时标识随行带出；常驻标识滚动后仍可见。
