# 第二批裁决：额度、专项照护、社区、埋点、组合套餐

这五条都是「实现切片开工前必须定的口径」，各自挡住一张票。合并成一份 ADR 是因为它们**互不依赖**（任一条改动都不影响其它四条），拆成五份只会让索引更长——[ADR-0019](0019-reminder-system.md) 也是这个处理方式。

## 一、AI 免费额度：计数但不拦截（挡 #98 收官、#112）

交付文档 F006 写「免费用户每日 3 次」，`ai.quota.free-per-day` 已经是 3。但**现在没有任何解锁路径**——「邀请/打卡解锁无限次」在 [#112](https://github.com/QIUZI-HONG/pet-health/issues/112) 权益引擎里。

**决定：计数 + 在响应里回报剩余次数，不拦截。** 到 3 次不返回错误，只让界面提示「今日免费咨询已用完，邀请好友可增加次数」。理由：拦截会把用户挡在一扇**没有出口**的门后面；而计数先跑起来能拿到真实用量分布——它比任何估算都更能决定 #112 的阶梯怎么定。等 #112 落地时把开关一翻即可，不需要改数据结构。

计数口径：**所有咨询都算一次**（含红线短路），按用户 + 业务日（`AppTime.today()`）计。

## 二、专项照护模式：派生态，不落状态位（挡 #116）

F009 说「7 岁以上或录入慢病自动开启」。#116 要定的是年龄怎么算、慢病解除后怎么办。

**决定：「是否处于专项照护」是个派生事实——按生日实时算、慢病解除即退出，不落任何「已开启」状态位。** 与健康评分的老年专项同一口径（那里已经是生日实时算 + 慢病判定，见 `HealthScoreService.isElderlyEnabled`）。

落一个状态位就多一处「状态与事实不一致」的可能（生日到了没开、慢病取消了还开着），而它没有任何独立性可言——完全由生日与慢病推导得出。历史报告不回改：报告记的是**出报告那一天**的判定。

年龄阈值仍是占位（犬 <1/1–7/>7、猫 <1/1–10/>10），与 63 号调研 §2.3 一致：**要兽医定稿**。

## 三、社区：只做自动生成的经验卡片（挡 #117，部分延后）

交付文档要「同款宠友圈、慢病社群、问答互助、经验卡片」，且明确**不做独立 Tab**（嵌在首页/AI/档案里）。

**决定分两步，本期只做第一步：**

1. **本期**：服务报工**自动生成**的经验卡片 + 按品种/病症聚合的卡片流，在首页与 AI 页各嵌一个入口（交付文档 4.16.2 / 4.16.3 画的就是这两处）。**不做发帖、不做评论、不做点赞。**
2. **静态入口先放**：「慢病 / 老年 / 训练」三个社群入口只放入口页，点了说明「即将开放」——它需要的内容运营能力现在不存在，做出来也是空的。

**为什么不做 UGC：** 经验卡片的原始动机是「录入即生成卡片（匿名）」，也就是**从真实报工里长出来的内容**；而 [#107](https://github.com/QIUZI-HONG/pet-health/issues/107) 报工还没落地，现在做发帖等于做一个空社区，还要连带做内容审核（#118 的一部分）。等 #107 有真实报工数据，再评估是否开放 UGC。

## 四、埋点：先做库里已有的数据 + 一条主观反馈（挡 #119）

**决定：**

1. **本期**：事件表 + 服务者/运营两端的最小看板——订单数、核销数、AI 咨询数、**红线命中数**。这些数据全在库里，不依赖任何前端埋点。
2. **本期加一条主观反馈**：「这条 AI 回答有帮助吗？」——它是**唯一能验证分级质量的产品信号**（比离线评测集的准确率更接近真实）。落成 `ai_consult.feedback`（有用 / 没用 / 未评）。
3. **不做**：前端行为埋点（页面浏览、按钮点击）。在用户量与 [合规 #74](https://github.com/QIUZI-HONG/pet-health/issues/74) 都没落地前，收益与隐私风险不成比例。

## 五、组合套餐：平台定组合模板，服务者只能组包与定价（挡 #106）

地图上已记「平台定骨架、服务者组包定价」，这里定细到可实现的形态。

**决定：组合模板 = 标准服务项的**有序集合** + 平台给的价区间。** 服务者只能在这个集合里组包，定价必须落在区间内（与单品的区间校验同一套机制，见交付文档 13.2 的价格区间落地）。

**不选品类级规则**（如「任意 2 项洗护类 ≥9 折」）：那会与券体系（#110 的「券适用范围」）语义重叠，两套折扣逻辑并存时「实付怎么算」会变成一句谁都说不清的话——而 ADR-0002 之后实付只是**展示值**，更不该引入第二套折扣语义。
