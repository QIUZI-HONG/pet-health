## Parent

#25（地图：C 端（Web + H5）——用户自助侧可演示产品）

## What to build

- **部署**：为 `app/` 加 Dockerfile 与 nginx 配置——照搬后台那份（SPA + 同域反代 `/api`；用 resolver + 变量的写法，后端没起来时前端容器**不 `[emerg]` 退出**）；`docker-compose.yml` 加一个服务与新端口（如 8081）。**后台 80 端口的形态不动。**
- 按 `docs/design/deploy-runbook.md` 部署到云主机；安全组 / 防火墙放行新端口；`SEED_DEMO_DATA=true` 时种子演示账号可登录。
- **验证**：手机浏览器（4G 或同网）与**微信内打开**各走一遍主线（打卡 + AI 问答）；`scripts/remote-selfcheck.sh` 增加 C 端检查项。
- **记录**：C 端访问地址与注意事项补进部署手册。

## Acceptance criteria

- [ ] 云主机 `docker compose up -d` 后 C 端地址可打开、能注册登录
- [ ] 手机浏览器与微信内各走通一条主线
- [ ] 后台（80 端口）与后端不受影响（回归自检通过）
- [ ] 部署手册补 C 端章节（端口、排障）

## Blocked by

- C 端联调自动测试与冒烟扩展
