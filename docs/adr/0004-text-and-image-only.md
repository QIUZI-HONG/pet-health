# AI 只做文字与图片，语音走转写，视频不做

交付文档 F006 要求文字 / 图片 / 视频 / 语音四种输入。现收敛为两种原生模态：**文字与图片**走多模态模型；**语音**先转写成文字再进入文本链路；**视频理解不做**。

理由是文档自己定的非功能指标站不住：AI 问答 P95 < 3 秒，而视频理解是四类输入里单价最高、延迟最大的一类，多模态调用叠加大模型推理压不进这个预算。图片是宠物分诊里真正不可替代的模态（皮肤、耳道、排泄物），视频不是。

## Consequences

- 不需要视频转码与抽帧链路，存储与带宽成本显著下降。
- C 端输入区保留语音入口（转写后当文本发送），去掉视频入口。
- 交付文档 4.16.3 里"支持五种输入"的视觉稿与功能描述需要按此修正。
