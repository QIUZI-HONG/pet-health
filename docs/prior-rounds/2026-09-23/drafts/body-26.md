## What to build

把 C 端接口**一次性冻结**进 `docs/design/api-contract.md`（新增 C 端章节），沿用一期 §六「实现期增补」的纪律：新增审计动作要回填动作字典、与交付文档第六卷的差异要列表说明。冻结后，前端与后端的实现会话都按它写，**别各自发明字段名**。

端点族（字段、状态码、分页、幂等由本票定死）：

- `/app/auth/*`：手机号+密码注册 / 登录 / 当前用户 / 改密 / 手机号可用性检查。JWT 角色 `USER`，subject = `app_user.id`。
- `/app/pets/*`：我的宠物 CRUD（含防疫四日期）、健康档案聚合、健康记录（今日打卡 + 同日合并 + 修改重算）、健康评分与 6 分项、连续打卡天数。
- `/app/ai/consults/*`：单轮分析（文字/图片，必须带自己的 pet_id）、历史与详情、重新分析、**每日 3 次配额**（响应带已用/剩余；超限 429 + 固定文案）、**合规标识**（每条回答固定文案 + 红色等级的就医准备清单）。
- `/app/messages/*`：派生消息流（健康预警 + 预约状态流转，倒序合并分页）+ 未读数 + 标记已看。
- `/app/providers/*`、`/app/service-items/*`：仅已通过审核且未停用的服务者、服务项、未来 14 天号源（按日期查余量）。
- `/app/appointments/*`：建单（只能用自己的宠物；同步建订单、无支付；地址默认取 `app_user.address`，可覆盖）、我的预约列表/详情、取消（必填理由）。
- `/app/files/*`：图片上传（AI 图片咨询用）——复用一期文件存储，本票定路径。

同时冻结：

- **数据范围规则**：一切资源以 `app_user.id` 为界，服务端强制，越权 403。
- **错误码用法**：401 / 403 / 404 / 409 / 422 / 429（配额）各自场景。
- **DDL 变更清单**（供迁移票照做）：`app_user` 加 `password_hash` 与 `messages_seen_at`、`phone` 唯一约束（NULL 不冲突）、`source` 允许 `SELF`、相关注释同步改（原文写「一期一律 PROXY」）。
- **消息与未读口径**写死（推荐：派生流 + `messages_seen_at` 单列，不新建表；若判断需要表，给结论与理由）。
- **配额口径**写死：只计 `source=SELF`。
