## Parent

#25（地图：C 端（Web + H5）——用户自助侧可演示产品）

## What to build

- **服务线**（从首页入口进）：服务者列表（类型 / 名称 / 简介）→ 详情（服务项列表）→ 选服务项 → 选日期与号源（显示余量）→ 预约确认页（选自己的宠物、地址默认取个人默认地址可覆盖、显示金额）→ 提交成功页。
- **我的预约**：列表（进行中 / 历史）、详情（状态、时间、地址、金额、状态流转）、取消（必填理由，二次确认）。
- **我的 Tab**：头像昵称、我的宠物（列表 + 建档 / 编辑入口）、我的预约入口、消息入口、AI 记录入口、退出登录。

## Acceptance criteria

- [ ] 完整走通：浏览服务者 → 选号源 → 建单成功 → 在「我的预约」看到「待确认」
- [ ] 满号 / 已关闭号源在界面层被禁用或给出明确提示
- [ ] 取消预约必须填理由；取消后状态正确、号源释放
- [ ] 超出 14 天窗口与已过时段不可选（与后端规则一致）
- [ ] 只能用自己宠物建单（界面不出现他人宠物）
- [ ] 我的宠物可建档 / 编辑，改动即时反映在首页与档案页

## Blocked by

- C 端应用骨架与登录注册
- C 端消息与服务预约接口
