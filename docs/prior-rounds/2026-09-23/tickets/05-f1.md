## Parent

#25（地图：C 端（Web + H5）——用户自助侧可演示产品）

## What to build

新建 C 端前端工程 `app/`：Vue 3 + Vite + **Vant 4**，**一套响应式**（移动优先；桌面宽度自适应，不另做版式）。

- **工程与脚本**：独立 `package.json`；`scripts/serve-app.sh`（容器内 dev，代理 `/api` 到后端，端口如 5174）与构建脚本；`vite.config.js` 与一期前端同构（proxy 目标可用环境变量覆盖）。
- **路由与框架**：底部 4 Tab（首页 / 档案 / AI 管家 / 我的）+ 二级页路由骨架；未登录拦截到登录页。**吸取一期教训**：后端不可用时要有明确提示，**不许白屏**。
- **鉴权**：注册页（手机号 / 密码 / 昵称）、登录页、token 存储与请求自动附加、退出；接通 `/app/auth/*`。
- **视觉**：交付文档第三卷的色彩 / 字号 / 圆角落成全局样式（主色 `#4CAF7D`、辅色 `#FF8A5C`、危险 `#FF6B6B`…）。

## Acceptance criteria

- [ ] `scripts/serve-app.sh` 起得来，手机浏览器（同局域网）可访问
- [ ] 注册 → 登录 → 进首页（空态）→ 退出，全流程可用
- [ ] 未登录访问任意 Tab 落到登录页；后端不可用时页面有明确提示、不白屏
- [ ] `npm run build` 可出产物
- [ ] 底部 4 Tab 与二级页路由骨架齐备（页面内容可为空态）
