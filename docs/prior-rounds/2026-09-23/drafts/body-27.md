## Parent

#25（地图：C 端（Web + H5）——用户自助侧可演示产品）

## What to build

C 端能注册登录，这是后续所有 `/app/**` 端点鉴权与数据范围的地基。

- **DDL 迁移**（Flyway；按 `docs/design/ddl-v1.sql` 顶部修订史的纪律升版本）：`app_user` 加 `password_hash`（可空——历史代录行无密码）与 `messages_seen_at`（若契约票定用）；`phone` 唯一约束（NULL 不冲突）；`source` 允许 `SELF`；注释同步改（原文「一期一律 PROXY」已过期）。
- **鉴权**：JWT 增加角色 `USER`，subject = `app_user.id`；`SecurityConfig` 放开 `/api/v1/app/auth/**` 公开，其余 `/app/**` 要求 `USER`；**不得影响现有 P/O 端点**。
- **端点**：注册（手机号 + 密码 + 昵称；手机号重复 409）、登录、`/me`、改密。
- 密码策略与一期一致（BCrypt、最小长度、登录失败锁定沿用一期实现，别另起一套）。
- 演示账号（手机号 + 密码）落进种子/演示数据脚本——本票先保证「账号能登录」，其名下的宠物与记录由「演示脚本与种子账号收尾」票负责。

## Acceptance criteria

- [ ] Flyway 迁移在真 MySQL 上跑通，`app_user` 新列与唯一约束生效
- [ ] 新手机号可注册并登录拿到 token；重复手机号 409；密码错误 401
- [ ] 未登录访问 `/app/pets`（任意受保护端点）401；`PROVIDER` / `OPERATOR` 的 token 访问 403
- [ ] 一期后台端点的测试全绿（回归未被破坏）
- [ ] 注册与登录写审计（动作字典已由契约票补）
- [ ] HTTP + 真库的 API 测试覆盖以上路径

## 补充（2026-09-23 大厂规划盘问）

- **会话策略**（ADR-0011）：C 端 token 单独设 **30 天**（后台维持 8 小时）；给 `app_user` 加**失效版本号**，改密 / 注销 / 全端登出时递增，旧 token 立即失效。
- **手机号是登录标识**，不是已核验凭证（演示档无短信）；注册/登录的**最小限流**在「账号生命周期」票实现，本票把接口留好。
- 追加验收项：改密后旧 token 立即 401，重新登录签发的新 token 正常可用。
