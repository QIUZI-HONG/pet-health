# 文档地图

`docs/` 下的东西性质不一样：有的是**规则**（改了要遵守），有的是**输入**（甲方给的，不是我们能改的），
有的是**归档**（留证据，不必精读）。这张表说明哪个是哪个，免得把归档当规矩、或者反过来。

新人（或 AI）最快上手的三份，按顺序：**[`../README.md`](../README.md)**（怎么跑）→
**[`../ARCHITECTURE.md`](../ARCHITECTURE.md)**（怎么连起来）→ **[`../CONTEXT.md`](../CONTEXT.md)**（怎么叫）。

## 一个已知的归档限制

`testing/` 的报告会引用 GUI 实测截图（`testing/screenshots-<日期>/`），那些 PNG
**不入库**（几十张图，体积压过文档本体），只存在于产出它们的那台机器上。
所以在别人机器上打开报告，截图是看不到的——正文的结论与缺陷编号仍然完整。

`.gitignore` 里的那条规则写清了这件事，别误以为「仓库里应该有」。
