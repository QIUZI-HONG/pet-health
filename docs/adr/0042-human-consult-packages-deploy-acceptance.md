# 第九批裁决：转人工与订阅、组合套餐、部署形态、验收口径

四条互不依赖，合并（同 [ADR-0024](0024-quota-care-community-tracking-packages.md)）。

## 一、转人工咨询与订阅（挡 [#71](https://github.com/QIUZI-HONG/pet-health/issues/71)）

- **转人工 = 咨询请求 + 后台认领**：用户在 AI 管家点「转人工」→ 生成一条**咨询请求**（进消息中心，同时在服务者/平台后台生成待认领工单）→ 由服务者或平台兽医**认领并回复**，会话走站内消息（[ADR-0019](0019-reminder-system.md) 的消息中心）。
- **39 元是展示价，必须标明「线下结算」**（[ADR-0036](0036-money-semantics-offline.md)：平台不经手资金）。不标价也可以，但不许标了价却不说明在哪付。
- **订阅本期不做**：没有支付载体（线上订阅无从收款）。权益引擎（[ADR-0038](0038-order-redeem-rights-points.md)）保留 `订阅` 来源的位置，但**没有产出路径**；真要订阅只能「线下签约 + 后台标记有效期」，形态等 #71 另议。
- **待甲方澄清**：转人工的成本归属——用户付给谁、平台与兽医如何分成。没有这条，转人工只能做成「免费导流」，而这与文档的 39 元定价意图不符。

## 二、组合套餐（挡 [#89](https://github.com/QIUZI-HONG/pet-health/issues/89) → #106）

- **平台定骨架 + 服务者组包定价**（与地图已记的基准一致）：平台定义套餐骨架（包含哪些标准目录项、哪些是必修项），服务者按骨架组包、在「**各项平台区间之和**」的范围内报价。
- **套餐在订单里展开成多个订单项**：保留单项的追溯、核销粒度与考核口径。**套餐不是新的计价单位**——它不产生平台级价格，只有服务者的报价。
- 由此推论：券的适用范围、考核的券口径都按**订单项**算，不按套餐算。

## 三、部署与环境（挡 [#66](https://github.com/QIUZI-HONG/pet-health/issues/66) → #122）

- **一份 compose 起全栈**：nginx（前端静态产物 + 反向代理）+ 后端 + AI 服务 + MySQL + Redis。
- **环境变量纪律沿用 README**：密钥无默认值、缺了启动即失败；后端的 `AI_SERVICE_TOKEN` 与 AI 服务的 `INTERNAL_TOKEN` 必须一致（不一致的表现是「带图咨询静默降级」，踩过）。
- **上线前置清单**（逐条勾，勾完才允许切流量）：备份与恢复演练、迁移回滚演练（已有 `server/scripts/undo-drill.sh`）、监控与告警接入、渗透测试、容量配置（[ADR-0041](0041-community-security-test-perf.md)）。
- **不做 K8s、不做金丝雀**：灰度改为「先起一套**预发环境**，用同一份 compose 跑一遍核心链路，再切流量」；回滚靠镜像标签 + compose（[ADR-0003](0003-lean-middleware.md) 的精简口径延续）。

## 四、交付物与验收口径（挡 [#68](https://github.com/QIUZI-HONG/pet-health/issues/68)）

- **交付主件**：代码 + 契约 + 迁移与 undo + 三套测试报告 + ADR 全集 + **偏离清单** + 一键复现命令。
- **验收按「F001–F027 逐条 + 偏离逐条」走**；**明确不采用**与现状冲突的验收条目：36 个页面全部可访问、真实小额支付跑通、iOS/Android/小程序三端兼容、性能三条硬指标（ADR-0041 已改写）、微信登录（ADR-0027 已裁决不做）。
- **偏离清单是三列表**：文档要求 / 我们的做法 / 依据的 ADR。**最新一轮验收报告的第四节**是它的唯一维护点
  ——本 ADR 原文指的是 `docs/testing/acceptance-2026-09-29.md`，而那份已被其后两轮报告取代；
  2026-09-30 复查时把指针改成「最新一轮」，免得每写一轮报告就要回来改一次 ADR（报告约定见 `docs/testing/` 的目录）。
- 「交付物清单」里**不承诺培训文档、压测报告、回滚演练记录**这三类甲方原文要求但尚未产出的东西——它们逐项列进上线前置清单（第三节）或明确标注为未产出。

## Consequences

- 转人工与订阅都建立在**待澄清的成本归属**上；在澄清之前，两者都只能做到「通道打通、钱不经平台」。
- 套餐展开成订单项意味着 `order_item` 是唯一的价格与核销落点，套餐表只描述骨架与成组关系。
- 预发环境不是可选步骤：它是「没有 K8s 但要有回滚能力」这条约束的替代品，缺了它，上线就只有一次机会。
