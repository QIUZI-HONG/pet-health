# 全 Web 化：三个端都是 Web，不做小程序与移动 APP

《宠物AI健康管理平台 · 全栈开发交付文档》原定微信小程序 + 安卓 APP + iOS APP 三端，用 uni-app 一套代码编译。现改为三个端全部是 Web：C 端为桌面浏览器访问，商家后台与运营后台是两个独立的 Web 后台。小程序、APP、uni-app 均不交付。

## Consequences

交付文档中依赖微信生态与移动端的能力同时失去载体，需要逐一替换——这是本次改版的主要成本，也是后续决策的入口：

- **微信登录** → 改为账号 + 密码
- **微信支付** → 不线上收款，见 [ADR-0002](./0002-offline-payment.md)
- **订阅消息推送** → 只剩站内消息中心，没有任何外部触达通道
- **小程序码 / 分享海报** → 邀请裂变失去二维码载体，需重新设计分享与归因方式
- **扫码核销** → 桌面浏览器没有默认扫码能力，核销流程需重新设计
- **手机尺寸视觉稿** → 现有 420×836 的 C 端视觉稿作废，36 个页面按 1440px 桌面基准重排。曾考虑保留手机尺寸、在桌面居中展示以零成本复用视觉稿，未采纳
