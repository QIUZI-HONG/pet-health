## Parent

#25（地图：C 端（Web + H5）——用户自助侧可演示产品）

## What to build

把 C 端账号**真正接通**（骨架票完成、后端账号鉴权票就绪之后）：

- 注册（手机号 + 密码 + 昵称）→ 登录 → 进首页空态 → 退出的完整链路。
- token 存储与自动附加；失效后的行为（回到登录页 + 说明原因，不白屏、不静默失败）。
- 改密 / 注销导致旧 token 失效时，其他设备下次操作被引导重新登录。
- 登录态 30 天的体验：刷新页面与次日打开不被迫重登。

## Acceptance criteria

- [ ] 新手机号注册 → 登录 → 首页空态 → 退出，全流程在手机上可用
- [ ] 重复手机号注册给出明确错误；密码错误提示清晰
- [ ] token 失效（被改密 / 注销）后，下一次请求引导回登录页并说明原因
- [ ] 刷新与次日打开不会被强制重登
