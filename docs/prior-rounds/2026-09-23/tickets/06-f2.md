## Parent

#25（地图：C 端（Web + H5）——用户自助侧可演示产品）

## What to build

C 端健康主线的界面（交付文档 §1.4.1 每日记录流程）：

- **首页**：今日健康任务卡片（5 项打卡，逐项 3 秒可完成——体重输入，饮食/排泄/行为/卫生选择 + 可选备注）、完成进度、连续打卡天数、宠物切换；**空态引导**（没有宠物时引导建档）。
- **打卡录入弹层**：提交后 toast + 进度即时刷新（同一项每日只计一次）。
- **健康档案 Tab**：宠物基础信息、健康评分（圆环 + 6 分项）、记录时间轴（按日期倒序、可翻页）、连续天数。
- **宠物建档 / 编辑页**：名称、物种、品种、年龄、体重、头像上传、慢性病标签、防疫四日期。

## Acceptance criteria

- [ ] 5 项打卡可逐项完成，进度与连续天数即时更新
- [ ] 同日重复打卡为合并而非新增（与后端语义一致）
- [ ] 评分圆环与 6 分项取自真实接口；时间轴可翻页
- [ ] 无宠物时空态引导可走到建档页并建成第一只宠物
- [ ] 手机宽度（375）与桌面宽度下都不出现横向滚动或遮挡

## Blocked by

- C 端应用骨架与登录注册
- C 端宠物与健康线接口
