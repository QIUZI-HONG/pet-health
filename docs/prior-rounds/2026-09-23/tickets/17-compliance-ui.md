#25（地图：C 端（Web + H5）——用户自助侧可演示产品）

## What to build

把合规要求变成用户看得见的界面：

- **《用户协议》《隐私政策》静态页**：写明收集项（手机号、宠物资料、健康记录、图片）、用途、保存期（网络日志 ≥ 6 个月、AI 咨询 12 个月、健康数据至注销）、第三方 AI 处理告知（调用外部大模型做分级）、AI 标识说明与免责、联系方式。措辞可先起草，但需人工过一遍。
- **注册页勾选**：未勾选不能提交（默认不勾选）。
- **我的-账号与安全-注销账号**：二次确认 + 后果说明（数据删除不可恢复）。
- **帮助与联系方式**：并入协议页或我的页的一个说明项（不做工单系统）。

## Acceptance criteria

- [ ] 两份协议可在未登录状态下打开（登录页与注册页都有入口）
- [ ] 未勾选协议时注册被拦下
- [ ] 注销走完二次确认后账号确实注销（与后端行为一致）
- [ ] 协议里写明的留存期与后端清理任务实际一致

## Blocked by

- C 端应用骨架与登录注册
- C 端账号生命周期与留存清理
