#25（地图：C 端（Web + H5）——用户自助侧可演示产品）

## What to build

C 端 AI 管家的后端：把一期「代录咨询」的能力开放给用户自助，并加上配额与合规标识。

- `POST /app/ai/consults`：文字或图片（图片走一期文件上传），必须带**自己的** pet_id；复用一期分级管线（规则兜底 + 模型增强取更保守一侧；硬红线直接判红，不走模型）。
- **每日 3 次配额**：只统计 `source=SELF` 的咨询（运营代录不占用户额度）；超限返回 429 + 固定文案（契约票冻结）；每次响应带已用/剩余次数供前端展示。
- **合规标识**：响应固定带 AI 生成标识文案；红色等级附「就医准备清单」（宠物基本信息 + 症状摘要 + 已给建议）。标识文案以研究票的结论为准（未回之前先用契约票冻结的文案）。
- 历史与详情：`GET /app/ai/consults`（仅自己的）、详情、失败重试（`analysis_status=PENDING` 重新分析，沿用一期）。
- AI 不可用时的降级（一期「提交成功、稍后通知」语义）在 C 端要说人话。

## Acceptance criteria

- [ ] C 端咨询写库为 `source=SELF`、`created_by` 为空
- [ ] 第 4 次当日咨询返回 429，文案与契约一致；次日恢复
- [ ] 代录咨询不占用户配额（回归覆盖）
- [ ] 响应含合规标识文案；红色等级含就医准备清单
- [ ] 查询他人咨询记录 403
- [ ] API 测试覆盖以上（配额计数直接查库断言）

## Blocked by

- C 端 AI 标识与留痕的合规口径核实（研究票）



## 补充（2026-09-23 大厂规划盘问）

- **标识文案以研究结论为准**（`docs/research/ai-content-labeling-compliance.md`，核实日期 2026-09-23）：每条回答固定 `本回答由 AI 生成，仅供参考，不构成诊断；如症状紧急请立即就医。`——该文案已满足显式标识的标准要素（含「AI」+「生成」、置于回答下方），**不需要改**；后端负责把标识随响应返回，展示要求（不可折叠 / 截断、复制带标识、颜色字号清晰）在前端票。
- **留存**：AI 咨询记录按 12 个月到期清理（清理任务在「账号生命周期」票）；**不提供「去标识化」展示选项**（《标识办法》第九条的条件性条款由此不触发）。
