# 文件与对象存储：先抽象，本期只落本地盘驱动

C 端的打卡拍照、服务者资质证件、疫苗本照片，以及 [#92](https://github.com/QIUZI-HONG/pet-health/issues/92) 的三道照片墙，全都依赖这一层；交付文档 6.2 要求「前端直传（STS 临时密钥）+ 上传回调验签」，而本机没有任何云账号可用（#66 部署方案未裁）。这一票要先给出一个**现在就能跑通、将来能换云**的形态。

## 决定

**一、存储走抽象 + 驱动**。接口 `FileStorage`（`presign` / `store` / `open` / `delete`），本期实现 `local` 驱动：文件落在可配置的根目录，上传地址由**后端用 HMAC 签发**（`PUT /api/v1/app/files/{id}/content?token=...`），浏览器把字节直接送到这个地址，不经过业务接口。生产环境的 `cos` 驱动作为第二个实现，等 #66 与云账号确认后再落——它只要满足同一个接口，业务代码不改。

**签名复用 `FIELD_HMAC_KEY`**，加 `upload-token:` 命名空间前缀，**不新增密钥配置项**。理由：多一个密钥就多一处「部署时忘了配」，而它已经是一个按环境隔离的 32 字节随机值；命名空间前缀保证同一个密钥在不同用途之间不可互换。

**二、上传协议对齐 COS 的形态，这样换驱动不是重写**。

| 环节 | 本期（local） | 生产（cos） |
| --- | --- | --- |
| 取凭证 | `POST /files/presign` 建**待传**行 + 返回签名地址与有效期 | 同一接口，返回 STS 临时密钥与对象键 |
| 送字节 | `PUT /files/{id}/content?token=` 直传，后端只做落盘与校验 | 浏览器直传 COS |
| 确认 | 直传即完成，行状态转**已传** | `POST /files/callback`，验签后转已传 |
| 读回 | `GET /files/{id}` 归属校验后回传（私有读） | 签发短时 URL |

**三、限制按交付文档 13.2 落地，但 MIME 以魔数判定**：只收 JPEG / PNG，单图 ≤ 10MB，一次 ≤ 9 张。**不信 `Content-Type` 请求头**——它由客户端自己填，等于没校验。视频不做（[ADR-0004](0004-text-and-image-only.md)）。

**四、缩略图后端生成，不引新依赖**：用 JDK 自带的 ImageIO 缩到宽 480 存 JPEG。交付文档 13.2 的「压缩质量 0.8」在这里落地；原图始终保留。

**五、「原图 + 局部特写」用 `role` 字段区分**，不建两张表：[#61](https://github.com/QIUZI-HONG/pet-health/issues/61) 发现视觉模型缩放会丢细节，所以要允许同一张照片额外传一张特写。`role` 取 `original` / `closeup` / `thumb`。

**六、文件默认私有**。读图必过归属校验（别人的文件按不存在处理，40400）；照片里是宠物与证件，不能靠 URL 猜。
*（2026-09-30 收窄）* 这句话对「上传者就是读者」的场景成立；跨身份读（三道照片墙、门店资质材料，
读者不是上传者）另按 [ADR-0053](0053-file-read-ownership.md) 处理——归属校验由业务模块用
`FileQueryApi#requireOwned` 承担。

**七、「拍照 → 拷到电脑 → 批量上传」就是多文件选择**：一次 `presign` 收多个文件，逐个上传。浏览器侧不做 IndexedDB 草稿（交付文档 2.4 的断点续传）：桌面 Web 的网络比移动端稳，且本地缓存要处理配额与失效，先不做，记为缺口而不是假装做了。

## Considered Options

**直接按文档上腾讯云 COS**：最贴近交付文档，但本机与 CI 都没有云账号，等于这一层写完**一行都验证不了**，照片墙与 AI 图片输入全部堵死。

**自建 MinIO**：接口与 COS 相近且能本地验证，但那就是新增一个常驻中间件，与 [ADR-0003](0003-lean-middleware.md)（精简中间件）冲突；而它带来的能力本期用不上。

**文件直接存 MySQL BLOB**：不新增任何组件，但把大字段塞进主库会让备份与迁移迅速变重，且与「对象存储」的演进方向相反。

**浏览器端压缩后再传（交付文档 13.2 的质量 0.8）**：省流量，但把「图片被压成什么样」交给一个可以绕过的客户端；本期在后端生成缩略图，原图不动。

## Consequences

照片与证件这条线现在能端到端跑通并**有测试**（魔数、体积、张数、签名篡改、过期、跨用户越权），换来的是**生产部署时要把 `cos` 驱动补齐**——这是明确的欠账，不是隐含的。

上传安全（病毒扫描、鉴黄）按分工归 [#81](https://github.com/QIUZI-HONG/pet-health/issues/81)，本模块只在 `FileStorage.store` 之后留一个校验钩子，不假装扫过。

文件是私有的，所以**前端拿到的永远是 `file_id` 而不是外链**；将来换 COS 私有读 + 短时 URL 时，前端不用改。
