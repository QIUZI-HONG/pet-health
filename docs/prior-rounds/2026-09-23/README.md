## 从这批文件里值得现在就知道的两件事

**1. 本机环境的坑（当时记下的，今天重新踩过一遍）**

- `gh` 走 `~/.local/bin/gh`，在脚本里要写全路径，且命令要加 `< /dev/null`——否则它会吞掉脚本的 stdin 导致**静默中断**
- `gh --body-file` 只认 **Windows 形式路径**（`C:\...`），WSL 的 `/mnt/c/...` 解析不了
- Docker 走 `~/.local/bin/docker` wrapper；挂 WSL 路径要用 UNC 形式

**2. 当时定下、今天仍然适用的纪律**

- 契约先行：先冻结接口契约，前后端各会话都按它写（与今天的 `contract/` + 生成机制同向）
- 每票一分支；四套验证（后端测试 / 端到端冒烟 / UI 真渲染断言 / 前端构建）
- 数据范围**服务端强制**、越权 403、**金额是字符串**、枚举大写、时间带时区
- 术语一律用 `CONTEXT.md`
